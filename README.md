# WORLD DOMINATION 3D — Prototype 0.1

A mobile browser game prototype packaged as an Android app with Capacitor.

## Build APK with GitHub Actions
1. Create a GitHub repository and upload all files from this folder.
2. Open **Actions** tab and enable workflows if prompted.
3. Run **Build Android APK** → **Run workflow** (or push to `main`).
4. Open the completed workflow run and download artifact `world-domination-debug-apk`.
5. Extract the ZIP and install `app-debug.apk` on Android.

This is an early prototype: stylized world map, country selection, budget, recruitment, simulated drone/missile strikes, diplomacy, and a lightweight battle scene. More countries, real map data, save system, and deeper 3D combat are future work.
